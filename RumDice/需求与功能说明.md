# RumDice 需求与功能说明文档

## 1. 项目概述

RumDice是一个基于C#开发的跑团机器人核心框架，旨在提供一个易于扩展、功能强大的机器人开发平台。该项目支持多平台接入（目前支持QQ和KOOK），并提供丰富的插件开发接口。

## 2. 系统架构

### 2.1 核心目录结构
- **Core/** - 核心功能模块
  - Initializer - 系统初始化
  - ClientConnector - 平台连接器（与gocqhttp等交互）
  - CoreData - 核心数据管理
  - EventManager - 事件处理系统
  - MessagePipeline - 消息处理管道
  - Startup - 系统启动入口

- **Framework/** - 框架服务
  - Attribute - 自定义属性定义
  - Datatype - 核心数据类型
  - Enum - 枚举类型定义
  - DataCenter - 数据存储中心
  - MessageTool - 消息处理工具
  - RumLogger - 日志系统
  - ServiceManager - 服务管理器

- **Module/** - 功能模块
  - Example - 示例模块
  - 自定义功能模块

- **Repository/** - 数据存储
- **Test/** - 测试程序
- **File/** - 文件资源

### 2.2 技术架构
- 开发语言：C#
- 目标框架：.NET
- 主要依赖：
  - EleCho.GoCqhttpSdk
  - Kook.Net
  - CS-Script
  - Newtonsoft.Json
  - gocqhttp

### 1.1 基础骰子系统
1. **标准骰子指令**
   - `.rd` - 投掷一个d100
   - `.rdn` - 投掷n个骰子
   - `.rdn+m` - 投掷n个骰子并加上m
   - `.rdn-m` - 投掷n个骰子并减去m
   - `.rdn#m` - 投掷n个骰子，取m个最高值
   - `.rdn$m` - 投掷n个骰子，取m个最低值

2. **特殊骰子指令**
   - `.rd优势` - 投掷两个骰子取高值
   - `.rd劣势` - 投掷两个骰子取低值
   - `.rd奖励骰` - 投掷带奖励骰的检定
   - `.rd惩罚骰` - 投掷带惩罚骰的检定
